\subsection{Logging and Exception Handling}
\label{sec:logging-exceptions}

The project uses Python’s standard \texttt{logging} library with a small wrapper in the shared library. At application entry, \texttt{setup\_logging()} configures a rotating file handler (writing to \texttt{\{LOG\_DIR\}/lichess.log}) and a stderr console handler, with the log level controlled by the \texttt{LOG\_LEVEL} environment variable (default \texttt{INFO}). Modules obtain a logger via \texttt{get\_logger(\_\_name\_\_)}. For error handling, a custom \texttt{LichessException} wraps caught exceptions: it logs an ERROR with traceback, preserves the original exception via chaining, and produces a human-readable message containing the file name, line number, and original error. This design ensures consistent observability and debuggability across all pipeline components.
