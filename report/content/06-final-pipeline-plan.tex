\subsection{Logging and Exception Handling}
\label{sec:logging-exceptions}

The project uses Python’s standard logging library with a small wrapper in the shared library. This wrapper provides a consistent logging interface across all pipeline components and allows for easy configuration of log levels and formats. Logs are structured to include timestamps, log levels, and contextual information about the pipeline stage and any relevant identifiers (e.g., game ID, player IDs). Implementation example code is shown in figure~\ref{fig:logging_example}.
