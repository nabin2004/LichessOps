\section[Dataset one]{Candidate dataset \textnumero\,1}
\label{sec:dataset-one}

\subsection{Purpose, provenance, and lineage}
\textbf{Lichess} is an open source online chess platform alternative to \textbf{chess.com}. It is famous for the handling the millions of games with being one developer only. Monthly it dumps the database of all games played on the platform. The dataset contains information about the players, the moves, and the outcomes of the games. The dataset is updated monthly and is available for download on the Lichess website. The dataset is used by researchers and developers to analyze chess games and to develop chess engines.

It can be obtained from \url{https://database.lichess.org/}. It is currently distributed in \texttt{.pgn.zst} format, a compressed variant of Portable Game Notation (PGN). The dataset is refreshed monthly and is available for download on the Lichess website.
A monthly shard inventory, licence summary, format sample, and ingestion caveats are collated for reproducibility in \cref{app:lichess-open-database}.

\subsection{Supervised modelling affordances}
The Lichess database is well-suited for supervised learning tasks, particularly with win/loss/draw outcome prediction. The dataset contains a large number of games, which provides a rich source of data for training machine learning models. The dataset also includes information about the players, such as their ratings and the time control of the game, which can be used as features for modeling. Additionally, the dataset is updated monthly, which allows for continuous learning and model improvement over time.

\section{Chosen dataset and justification}
\label{sec:chosen-dataset}

The \textbf{Lichess Open Database} was selected as the primary dataset due to its large scale, realistic data engineering challenges, rich machine learning features, and open CC0 licence. It supports both classification and regression tasks within the same records and has been widely used in prior research, providing reliable benchmarks. In contrast, smaller datasets such as Boston Housing and Wine Quality are useful only for basic proof-of-concept models because of their limited size and static nature.
