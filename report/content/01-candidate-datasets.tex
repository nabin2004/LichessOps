\chapter{Candidate source datasets (Exercise 1, Step 1)}
\label{ch:candidate-datasets}

This chapter records three plausible primary sources for supervised learning alongside the structured discussion required before any pipeline blueprint is credible.
Consistency across candidates makes comparative reading easier once the favoured dataset is defended in~\cref{sec:chosen-dataset}.

\section{Learning objective framing}
\label{sec:learning-objective}

State the predictive question, the intended label, approximate unit of analysis (row grain), constraints on latency and governance, how success will be measured, and regulatory or ethical sensitivities upfront.
Readers should understand why each candidate could support that objective without yet committing to ingestion mechanics.

\section[Dataset one]{Candidate dataset \textnumero\,1}
\label{sec:dataset-one}

\subsection{Purpose, provenance, and lineage}
Articulate what the data represents, who generated it and under which programme, sampling frame, freshness guarantees, licences, deduplication rules, known biases, documentation links, and any prior ML usage.

\subsection{Logical and physical portrayal}
Contrast the logical abstraction (tables, hierarchies, event streams, documents) against on-disk realities (indexes, parquet row groups, API pagination, blobs).
Readers should envision how exploratory queries behave before transformation.

\subsection{Supervised modelling affordances}
Clarify target variable derivation, plausible predictors, label noise, leakage risks, imbalance, fairness implications, temporal drift, baseline expectations, and how ground truth was recorded.
