\chapter*{Abstract}
\phantomsection
\addcontentsline{toc}{chapter}{Abstract}

This log report outlines the planning and design of a data management and analytics strategy for supervised machine learning within a chosen problem domain.It explains three supervised machine learning candidate datasets. We select the Lichess Open Database. It also outlines an MLOps pipeline covering data ingestion, pre-processing, model development, deployment, and monitoring, serving both interactive analysts (notebooks) and an automated model-training workflow. The design is justified with industry and research literature and it also anticipates iterative refinement as implementation begins.
